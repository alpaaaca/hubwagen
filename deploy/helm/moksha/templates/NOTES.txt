moksha {{ .Chart.AppVersion }} is starting in {{ .Release.Namespace }}.

The API and web UI (no authentication yet; reach it through a port-forward):
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "moksha.fullname" . }} {{ .Values.server.port }}
  open http://127.0.0.1:{{ .Values.server.port }}

Deploy a project (a moksha.yaml with kind: Project and a build image) from
its directory; the image goes to its registry and the server runs it by
digest, a Deployment per pool:
  moksha deploy --push --server http://127.0.0.1:{{ .Values.server.port }}
  kubectl -n {{ .Release.Namespace }} get deployments -l moksha.dev/instance={{ include "moksha.instance" . }}

helm uninstall leaves those Deployments; delete projects first (moksha
delete <project>), or afterwards:
  kubectl -n {{ .Release.Namespace }} delete deployments -l app.kubernetes.io/managed-by=moksha,moksha.dev/instance={{ include "moksha.instance" . }}
